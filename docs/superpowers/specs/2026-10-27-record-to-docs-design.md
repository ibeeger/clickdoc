# record_to_docs 设计文档

日期：2026-10-27
状态：已确认需求，待用户审阅文档

## 1. 意图

做一个类似 Folge 的 macOS 小工具，仅供作者自己使用。用途是：一边操作某个软件，一边自动记录每一步，最后生成一份带截图的 Markdown 使用教程。

第一版一切从简，先跑通"录制 → 编辑 → 导出 Markdown"这条主线，以后再丰富。

## 2. 目标

- 录制时，每次鼠标点击自动截一张图，并在点击位置画醒目的高亮标记（类似 Folge 的红圈效果）。
- 录制结束后，可以在应用里编辑步骤：改文字、删除步骤、调整顺序、改教程标题。
- 导出为一个文件夹：`tutorial.md` 加若干 PNG 截图。

## 3. 非目标（第一版不做）

- 不做 Windows / Linux，只做 macOS。
- 不做 HTML、PDF、Notion、飞书等其他导出格式。
- 不做草稿保存或项目持久化。关闭窗口，未导出的内容就丢失。
- 不做键盘输入记录、不录视频、不做 AI 生成描述。
- 不支持在编辑界面里调整高亮标记的位置或样式。
- 不做截图裁剪、打码、标注等图片编辑。
- 不考虑分发、公证、自动更新，只在作者本机运行。

## 4. 反目标（即使能跑也算失败）

- 截图里看不清点了哪里（标记不醒目或位置偏移）。
- 点击本应用自己的界面（菜单栏图标、停止按钮）被记成步骤。
- 录制时明显卡顿，影响正常操作被录软件。
- 导出的 Markdown 在常见查看器（VS Code、Typora、GitHub）里图片显示不出来。

## 5. 用户已确定的部分

### 5.1 录制

- 应用常驻菜单栏，有一个图标。菜单里有"开始录制"和"停止录制"。
- 开始录制后，全局监听鼠标点击。
- 每次点击：
  - 截取点击所在那个显示器的整屏画面。
  - 在点击位置把高亮标记直接合成进截图（不保留无标记的原图）。
  - 记录时间、点击坐标、前台应用名，以及通过辅助功能 API 拿到的被点控件名称或角色。拿不到就留空。
  - 自动生成一句描述，例如"在 Safari 中点击「新建标签页」"。拿不到控件名时，退化为"在 Safari 中点击"。
- 点击本应用自身的界面不计入步骤。
- **截图时机（用户决定）**：点击后立即单次截图，不在后台持续抓屏。接受截图偶尔反映"刚点完"的状态（如菜单已弹开、按钮呈按下态），以换取实现简单、录制不卡。

### 5.1.1 继续录制（用户决定）

- 编辑窗口中已有未导出的步骤时，再次"开始录制"会把新步骤追加到当前教程末尾，相当于暂停后继续。
- 不清空、不提示。想重新开始，需要另外提供"新建教程"操作（会提示未导出内容将丢失）。
- 录制期间编辑窗口可以保持打开，但对它的点击不计入步骤。

### 5.2 编辑

- 停止录制后弹出主窗口。
- 左侧：步骤列表，每项显示缩略图和描述文字。
- 右侧：选中步骤的大图预览，以及可编辑的描述文字。
- 支持：修改描述、删除步骤、拖动调整顺序、修改教程标题。
- 顶部有"导出"按钮。

### 5.3 导出

- 点"导出"后选择一个目录，在其中生成一个以教程标题命名的子文件夹。
- 子文件夹内容：
  - `tutorial.md`
  - `images/step-01.png`、`images/step-02.png` …（按最终顺序重新编号）
- Markdown 格式：

```markdown
# <教程标题>

## 步骤 1

<描述文字>

![步骤 1](images/step-01.png)

## 步骤 2
...
```

- 图片使用相对路径。

### 5.4 权限

- 需要"屏幕录制"和"辅助功能"两项权限。
- 首次运行或权限缺失时，给出提示并提供按钮打开对应的系统设置页面。

## 6. 约束

- 平台：macOS 14 及以上（本机为 macOS 15.7）。
- 本机没有安装 Xcode，只有 Command Line Tools（Swift 5.9.2，macOS SDK 14.2）。构建必须能在这个环境下完成。

## 7. 我（Claude）替用户做的决定

这些是我的选择，用户没有专门讨论过，可以推翻：

- **语言和框架**：Swift + SwiftUI，原生 macOS 应用。
- **构建方式**：因为没有 Xcode，用 Swift Package Manager 构建可执行文件，再用一个 shell 脚本组装成 `.app` 包（放入 Info.plist，并进行签名）。不使用 Xcode 工程文件。
- **截图 API**：ScreenCaptureKit（`SCScreenshotManager`，macOS 14 可用）。
- **点击监听**：`CGEventTap` 或 `NSEvent.addGlobalMonitorForEvents`，只监听左键按下。
- **高亮样式**：半透明红色实心圆加红色描边圆环，直径约 60pt，随屏幕缩放系数换算到像素。
- **点击规则**：
  - 左键单击记为一步。
  - 双击合并为一步：同一位置附近、间隔在系统双击阈值内的第二次点击不再新建步骤，描述改为"双击"。
  - 右键单击也记为一步，描述为"右键点击"。
  - 拖动只按起点的按下事件记一步，不额外处理。
- **菜单栏应用**：用 `LSUIElement` 隐藏 Dock 图标；主编辑窗口出现时可临时显示。
- **数据只在内存中**：录制会话的截图以内存或临时目录形式保存，导出后不保留。
- **签名与权限**：每次重新编译后，临时签名（ad-hoc）的应用会被系统视为新应用，需要重新授权。推荐在钥匙串里创建一个自签名证书用于稳定签名，避免反复授权。构建脚本应支持指定签名身份，默认退回 ad-hoc。

## 8. 留给实现者决定

- 代码模块划分和文件结构。
- 点击位置的坐标系换算细节（多显示器、Retina 缩放）。
- 截图耗时较长时的处理方式（例如异步截图、排队），只要不造成明显卡顿。
- 控件名称的获取策略（`AXTitle`、`AXDescription`、`AXRoleDescription` 的优先级）。
- 编辑窗口的具体布局细节和样式。
- 导出时文件夹重名的处理方式。
- 测试策略：对纯逻辑部分（描述生成、Markdown 生成、导出文件编号）写单元测试；涉及系统权限的部分手动验证即可。
